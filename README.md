📊 Description du Dashboard – Centre de Formation

Ce dashboard Power BI a été conçu pour offrir une vue interactive et synthétique de l’activité d’un centre de formation. Il permet de suivre les performances commerciales, les inscriptions des apprenants, les abandons ainsi que l’efficacité des différentes formations et sources de recrutement.

Le tableau de bord est organisé autour de plusieurs axes d’analyse :

Performance globale : les KPI permettent de suivre rapidement le nombre d’inscriptions, le montant total payé, le nombre d’abandons ainsi que les taux d’abandon et de complétion.
Analyse des formations : les différentes formations sont comparées selon le montant encaissé, le nombre d’inscriptions et le nombre d’abandons afin d’identifier les tendances de performance.
Analyse marketing : le treemap permet d’analyser les inscriptions selon les différentes sources marketing telles que Facebook, Instagram, Google, WhatsApp, LinkedIn, les recommandations et les événements.
Analyse géographique : la carte interactive permet de visualiser la répartition du montant payé selon les différentes villes de Tunisie.
Analyse des facteurs de réussite : le graphique central met en évidence la relation entre les scores aux examens et le nombre de formations complétées.
Filtrage temporel : le sélecteur de dates permet d’analyser les résultats sur une période spécifique.
🎯 Objectif

L’objectif principal est de transformer les données du centre de formation en informations facilement exploitables afin de suivre les performances, comprendre le comportement des apprenants et identifier les principaux facteurs liés aux inscriptions et à la complétion des formations.

🛠️ Technologies utilisées
Power BI
Power Query pour le nettoyage et la préparation des données
DAX pour la création des indicateurs et mesures
Visualisations interactives : KPI, graphiques, treemap, carte et filtres
💡 Résultat

Ce dashboard offre une vision 360° de l’activité du centre de formation et facilite le suivi des principaux indicateurs de performance grâce à une présentation interactive, claire et centralisée des données.
